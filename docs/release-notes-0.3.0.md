# Sidecar 0.3.0 (beta)

Sidecar turns a computer and audio interface into a live mixing console. 0.3.0 adds
many consoles and a new interface.

**New consoles:** X32, ProMix 01, 02R, 01V, SQ-5, dLive (C3500 and C1500), DM2000, PRO2 and
the XENYX Q1202USB, each with its own surface, pages and MIDI. The WING gets a RACK model.

**Universal Mixer:** nine themes, a CHANNEL panel with EQ handles and an RTA, user layers
you drag together, and plug-in blocks (VST3, AU, LV2) in any strip's chain.

**Blocks across consoles:** a WING EQ on a ProMix, a DM2000 compressor on an X32.

**Remote control:** drive a real X32 over the network. Only partly tested so far.

**Also new:** a start-up tile picker, console tape for channel names on the consoles without
name displays, and a benchmark in SETUP that shows what your PC can run, with one Sidecar Mark
score to compare computers.

**Polish:** a theme for each console, a full-screen view for every console's display, fader caps that keep their scales readable, and a routing page on the Q1202USB.

Many fixes and a lot of detail: see the CHANGELOG.

| macOS 11+ (Apple silicon and Intel) | `Sidecar-{version}-macOS.dmg` |

| Linux arm64 (Raspberry Pi 4 or 5, 64-bit OS; experimental, untested on a Pi) | `Sidecar-{version}-Linux-aarch64.tar.gz` |
