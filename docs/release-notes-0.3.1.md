# Sidecar 0.3.1 (beta)

A fix and polish release.

**New:** PLUGIN HOST, a console of Sidecar's own for hosting plug-ins on a real console's
inserts, with its own surface, and racks on any console's strip in the Universal Mixer.

**Faster:** quicker start-up, console switching and show loading; the audio engine and the
surfaces' drawing use less CPU.

**Consoles:** Dyn8 and UFX screens on the dLive, many dLive screens matched to photos, more
X32 display menus, a DM2000 meter bridge, touch-friendly user layers in the Universal Mixer.

**Fixes:** the web remote now works from the same computer and while Sidecar is minimised or
covered; Linux audio runs at realtime priority (fewer dropouts on a Raspberry Pi); channel
presets no longer share another channel's FX slot (#26); three WING fixes (#22-#24).

See the CHANGELOG for the detail.
